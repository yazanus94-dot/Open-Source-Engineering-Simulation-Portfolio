## Overview
Variational linear elasticity formulation on a box mesh with clamped/tip-traction boundary conditions, PETSc KSP solve, and XDMF output.

## Problem statement
Compute linear elastic deformation of a 3D cantilever beam under a tip traction and compare against Euler–Bernoulli theory.

## Original project notes
# FEniCSx - Cantilever Beam under Self-Weight (3D Linear Elasticity)

Variational formulation in UFL, Dirichlet BC on the clamped face, direct LU solve, mesh refinement study,
and **verification vs. Euler-Bernoulli** (delta = rho g A L^4 / 8EI).
Linear hexahedra (Q1) lock in bending, so expect under-prediction that shrinks with refinement - a useful
discussion point (try quadratic elements: `("Lagrange", 2, (3,))`).

```bash
conda create -n fenicsx -c conda-forge fenics-dolfinx mpich pyvista
conda activate fenicsx
python cantilever.py
```
Output: `displacement.xdmf` (ParaView).
