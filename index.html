Quick start

  • Clone the repo and install lightweight Python deps: pip install -r requirements.txt
  • Validate portfolio structure: python scripts/validate_portfolio.py
  • Open any project folder and follow its README (external toolchains required for execution).
  • Review docs/results.md for artifact and execution status.
